# かなジャン！Kana Jan

五十音學習用的 2～4 人回合制卡牌遊戲原型。第一版為 **1 名真人＋3 名電腦**，可在瀏覽器從頭玩到結束。

## 玩法（實作時採用的規則）

玩家收集假名卡，組成以下牌型得分：

| 牌型 | 內容 | 基礎分 |
| --- | --- | --- |
| 同音三張 | 同一讀音的平假名＋片假名＋單字圖像 | 3 |
| 同一行五張 | 同一行五個**不同**讀音，形式不限 | 6 |
| 同一段五張 | 本局五個行中同一段的五個不同讀音 | 8 |

同一行／同一段若五張都是同一 `cardType`：平假名 +3、片假名 +4、單字圖像 +5。

本局會隨機一個 Bonus 任務，結算時加在該牌型上。

### 回合

1. 自動抽 1 張（牌庫空則跳過）。
2. 若有合法牌型，可結算其中一組，或暫不結算。
3. **未結算必須棄 1 張**；結算後手牌 ≤ 7 則不棄牌，直接補到 7 張。
4. 棄牌後，其他玩家若能用這張牌完成牌型，可宣告「もらった！」。優先權為棄牌者之後的回合順序，可放棄後交給下一位。
5. 完成牌型的卡片移到完成區，不再計分。
6. 從牌庫補到手牌 7 張；不足則能補多少補多少。

### 金幣

- 自己抽牌完成（できた／自摸）：其他三人各付該牌型分數。
- 用別人棄牌完成（もらった）：只有棄牌者支付。
- 金幣不可低於 0；有人歸零則當次結算後結束。
- 牌庫在補牌後耗盡也結束。
- **排名以累計牌型分數為主，金幣為平手決勝。**

### 規格決策

- 每回合最多結算一個牌型。
- 第一版牌庫：あかさたな 五行 × 3 種卡片 = 75 張。
- 單字圖像卡目前用 emoji／icon，資料中保留 `image` 欄位以便日後換圖。
- 電腦分為簡單／普通，邏輯與 UI 分離。
- 所有洗牌、Bonus、起始玩家走 seed 亂數；UI 動畫延遲不進 seed。
- 重新整理會從 localStorage 恢復對局。

## 啟動

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:5173`）。

```bash
npm test          # 規則測試
npm run typecheck
npm run lint
npm run build
npm run preview   # 預覽正式建置
```

建議視窗寬度約 1024px 以上，或 iPad 橫向。

## 主要檔案

- `src/data/kana.ts`、`src/data/cards.ts`、`src/data/bonuses.ts`：牌組與任務資料
- `src/engine/yaku.ts`：牌型判定
- `src/engine/scoring.ts`：分數與金幣
- `src/engine/game.ts`：回合狀態機
- `src/engine/ai.ts`：電腦決策
- `src/engine/rng.ts`：可重現亂數
- `src/audio/`：語音與可替換音效介面
- `src/ui/`：畫面元件
- `src/engine/*.test.ts`：核心規則測試

# かなジャン！Kana Jan

五十音學習用的**固定四席**回合制卡牌遊戲原型；可由 **1～4 名真人**參與，其餘座位由電腦補滿。單機模式預設為 **1 名真人＋3 名電腦**，也可由房主建立 PeerJS 房間進行連線對戰。

## 玩法（實作時採用的規則）

玩家收集假名卡，組成以下牌型得分：

| 牌型 | 內容 | 基礎分 | 加成條件 |
| --- | --- | --- | --- |
| 同音三張 | 同一讀音的任意三張卡 | 120 | 三位相和（平＋片＋字 各一）+360＝480；純色 +720＝840 |
| 拗音／や行／わ・を・ん組揃い | 同一三音組三個**不同**讀音（拗音、やゆよ、わ・を・ん） | 180 | 純色 +300＝480 |
| 同一行五張 | 同一行五個**不同**讀音，形式不限 | 480 | 純色 +1320＝1800 |
本局會從登場行中隨機抽一個假名作為 Bonus 目標音（+90）。結算牌型中只要包含該讀音，無論是平假名、片假名或單字牌都會加分。同一段揃い已移除。

### 回合

1. 自動抽 1 張（牌庫空則跳過）。
2. 若有合法牌型，可結算其中一組，或暫不結算。**結算不要求牌型包含本次剛摸到的牌**；只要目前手牌內已有合法牌型即可宣告「できた！」。
3. **未結算必須棄 1 張**；結算後手牌 ≤ 7 則不棄牌，直接從牌庫補到 7 張。
4. **連鎖機制（Combo）**：補牌後若手牌中仍能湊成合法牌型，可持續宣告自摸（できた！），直到補滿 7 張沒有牌型可打或主動跳過，才換下一家（此時不需棄牌）。
5. 棄牌後，其他玩家若能用這張牌完成牌型，可宣告「もらった！」。優先權為棄牌者之後的回合順序，可放棄後交給下一位。抄牌完成牌型後亦會補滿 7 張手牌，若剛好湊齊牌型亦可無縫接續連鎖。連鎖結束後輪到原棄牌者的下一家；若下家就是抄牌者，則再順延一家。
6. 完成牌型的卡片移到副露完成區，不再計分。

### 金幣

- 每位雀士以 **1,000 點**開局（4 人合計 4,000 點）。
- 自己抽牌完成（できた／自摸）：其他三人平分該牌型分數。
- 用別人棄牌完成（もらった）：只有棄牌者全額支付。
- 金幣不可低於 0；有人歸零則當次結算後結束。
- 若付款者餘額不足，付款者扣至 0，贏家仍取得完整役值；不足額視為系統補足（事件紀錄會分開列出實扣與系統補足）。
- 教學關的「一行揃い」依登場五音行數調降：單行 180／純色 480，兩行 300／960，三行以上維持 480／1800。
- 牌庫在補牌後耗盡且無連鎖可打時也結束。
- **排名以局內剩餘金幣為主，累計牌型分數為平手決勝。**

### 規格決策（對齊 Poka Jan 機制）

- **隨機 4 行抽牌組**：2 組清音／濁音・半濁音（10 音）＋ 1 組拗音（3 音）＋ 1 組全牌組抽選（3 或 5 音），每局總音數固定為 16 或 18 音。
- **100 張牌庫**：每個讀音提供 9 張牌（平假名 3、片假名 3、單字卡 3），母池為 144 或 162 張。洗牌後切出前 100 張進入對局（發牌 28 張，山牌固定留 72 張，可抽 18 巡）。
- **同音任意 3 張即成牌**：大幅降低死聽機率，並以「三位相和（全彩）」與「純色」給予高額番數獎勵。
- 單字圖像卡目前用 emoji／icon，資料中保留 `image` 欄位以便日後換圖。
- 電腦分為簡單／普通，邏輯與 UI 分離。
- 所有洗牌、Bonus、起始玩家走 seed 亂數；UI 動畫延遲不進 seed。
- 重新整理會從 localStorage 恢復對局。
- `deckManifest`（每個讀音／牌面類型在本局開始時的總張數）視為**公開牌組構成資訊**；牌序、牌山內容與對手手牌仍為隱藏資訊。介面依公開總張數扣除已看見的牌，顯示的是「未見牌」，不是可精確推知位置的牌山內容。
- 語音優先使用本地檔案；缺少的 `や・ゆ・よ・わ・を・ん` 音檔會改用線上 TTS，線上服務不可用時再退回瀏覽器 Web Speech，因此這六音目前不保證完全離線。

## 啟動

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的本機網址（預設 `http://localhost:5173`）。

```bash
npm test          # 規則測試
npm run typecheck
npm run lint
npm run build
npm run preview   # 預覽正式建置
```

建議視窗寬度約 1024px 以上，或 iPad 橫向。

## 主要檔案

- `src/data/kana.ts`、`src/data/cards.ts`、`src/data/bonuses.ts`：牌組與任務資料
- `src/engine/yaku.ts`：牌型判定
- `src/engine/scoring.ts`：分數與金幣
- `src/engine/game.ts`：回合狀態機
- `src/engine/ai.ts`：電腦決策
- `src/engine/rng.ts`：可重現亂數
- `src/audio/`：語音與可替換音效介面
- `src/ui/`：畫面元件
- `src/engine/*.test.ts`：核心規則測試

# 音效與背景音樂檔案目錄 (Audio Assets)

本目錄存放《かなジャン！Kana Jan》的音效與背景音樂檔案。

支援格式：`.mp3`（推薦）、`.ogg`、`.wav`（系統預設路徑以 `.mp3` 為主）。

如果檔案尚未放入，遊戲會**自動無縫 fallback** 到 Web Audio 合成音，絕不中斷遊戲體驗。

---

## 📁 目錄結構

```
public/audio/
├── bgm/                  # 背景音樂 (循環播放)
│   ├── bgm-lobby.mp3     # 大廳主選單背景音樂
│   ├── bgm-table.mp3     # 牌桌對局背景音樂
│   └── bgm-tension.mp3   # 聽牌／高壓緊張背景音樂 (可選)
└── sfx/                  # 遊戲音效 (短音)
    ├── draw.mp3          # 摸牌音效
    ├── discard.mp3       # 出牌／切牌音效
    ├── dekita.mp3        # 湊到牌／自摸和牌音效 (できました！)
    ├── moratta.mp3       # 抄牌／榮和鳴牌音效 (もらった！)
    ├── ron.mp3           # 放槍／放銃受害音效 (點砲、衝擊音)
    ├── coin.mp3          # 籌碼結算／金幣轉移音效
    ├── click.mp3         # 按鈕與選牌點擊音效
    ├── win.mp3           # 最終對局第一名勝利音效 (Fanfare)
    ├── lose.mp3          # 最終對局破產／落敗音效
    ├── ready.mp3         # 聽牌提示音效 (可選)
    └── tick.mp3          # 計時提示音效 (可選)
```

---

## 🎵 檔案詳細說明清單

| 分類 | 檔案路徑 | 觸發時機 | 建議長度與風格 |
| :--- | :--- | :--- | :--- |
| **BGM** | `bgm/bgm-lobby.mp3` | 大廳畫面 | 30~90 秒循環，悠閒放鬆、和風或輕快咖啡廳風格 |
| **BGM** | `bgm/bgm-table.mp3` | 進入牌局對局中 | 60~120 秒循環，節奏輕快、專注和風（如三味線、輕敲擊） |
| **BGM** | `bgm/bgm-tension.mp3` | 牌局末尾、局勢緊張 (可選) | 30~60 秒循環，微緊張節奏 |
| **SFX** | `sfx/dekita.mp3` | **湊到牌**（自摸完成役） | 1.0~2.5 秒，明亮歡樂、成牌慶祝（如「できました！」或清脆和牌鈴聲） |
| **SFX** | `sfx/moratta.mp3` | **抄牌**（榮和別人的棄牌） | 1.0~2.0 秒，敏捷俐落、鳴牌奪牌（如「もらった！」或拔刀/鳴鈴音） |
| **SFX** | `sfx/ron.mp3` | **放槍**（自己打出關鍵牌被抓） | 1.0~2.0 秒，沉重衝擊、雷擊、摔碎或震驚音效 |
| **SFX** | `sfx/draw.mp3` | 輪到摸牌時 | 0.2~0.5 秒，清脆紙牌抽牌聲 |
| **SFX** | `sfx/discard.mp3` | 打出棄牌時 | 0.2~0.5 秒，木桌或麻將牌輕敲桌面的乾脆敲擊聲 |
| **SFX** | `sfx/coin.mp3` | 籌碼移動、結算轉移 | 0.5~1.0 秒，金幣碰撞落袋、籌碼堆疊聲 |
| **SFX** | `sfx/click.mp3` | 點選牌面、按鈕點擊 | 0.1~0.2 秒，乾淨微弱的介面反饋音 |
| **SFX** | `sfx/win.mp3` | 整局結束榮獲第 1 名 | 2.0~4.0 秒，熱烈勝利號角、慶祝 Fanfare |
| **SFX** | `sfx/lose.mp3` | 整局結束破產或墊底 | 1.5~3.0 秒，低沉遺憾失落小調 |
| **SFX** | `sfx/ready.mp3` | 叫聽／聽牌提示 | 0.5~1.0 秒，清脆叮聲或提示音 |
